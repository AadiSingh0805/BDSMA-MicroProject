from pyspark.sql import SparkSession
from pyspark.sql.functions import udf, col, regexp_replace, lower
from pyspark.sql.types import FloatType, StringType
from nltk.sentiment.vader import SentimentIntensityAnalyzer

# 1. Initialize PySpark Distributed Session
spark = SparkSession.builder.appName("TubePulse-Sentiment-Engine").master("local[*]").getOrCreate()

# 2. Distributed Text Sanitization (Emoji, URLs, Punctuation)
df_clean = df.withColumn("clean_text", 
    regexp_replace(regexp_replace(lower(col("text")), r"http\S+|www\S+", ""), r"[^a-zA-Z\s]", ""))

# 3. High-Throughput VADER UDF Polarity Mapper
sia = SentimentIntensityAnalyzer()
vader_udf = udf(lambda text: sia.polarity_scores(text)['compound'] if text else 0.0, FloatType())
df_scored = df_clean.withColumn("sentiment_score", vader_udf(col("clean_text")))

Academic & Industry Impact

Engineered for Big Data Rigor & High Simplicity

Every component was chosen to maximize academic evaluation marks while maintaining rapid execution without demanding heavy GPU compute.

Distributed PySpark Engine

Eliminates single-thread pandas memory bottlenecks. Performs tokenization, stop-word removal, and VADER scoring across distributed partitions with scalable Spark SQL and ML pipelines.

Spam & Bot Rule Engine

Flags automated bots, WhatsApp financial fraud numbers, Telegram crypto traps, and timestamp self-promotion strings. Calculates an instant Clean-to-Spam trust ratio for each video.

Audience Discrepancy Index

A novel metric comparing public Like-to-View ratios with true Comment Sentiment scores. Detects clickbait, misleading thumbnails, or videos with artificially boosted like counts.

TF-IDF Bigram Topic Mining

Extracts recurring two-word phrases to instantly reveal the specific root causes of viewer dissatisfaction or praise (e.g., "audio delay", "explained simply", "camera focus").
